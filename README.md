# Employee Attrition Data Analysis

## 5 Business Questions
1. Which department experiences the highest employee attrition rate?
2. Does monthly income significantly affect employee turnover?
3. What is the impact of overtime work on employee attrition?
4. How does job satisfaction correlate with the decision to leave?
5. Which age groups and experience levels are most prone to resign?

## Data Dictionary (Bonus)
| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| Age | Integer | Employee age in years |
| Attrition | Object (String) | Whether employee left the company (Yes/No) |
| Department | Object (String) | Department (e.g., Sales, R&D, HR) |
| MonthlyIncome | Integer | Monthly earnings in USD |
| OverTime | Object (String) | Overtime status (Yes/No) |
